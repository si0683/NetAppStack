# Техническое задание для ИИ: настольная программа для Windows

> **Как пользоваться:** скопируйте весь текст и вставьте в ИИ-ассистента. Или положите файл в папку проекта и напишите: «Прочитай PROMT.md и сделай по нему программу». Замените `«…»` своими данными, отметьте нужное `[x]`, лишнее удалите. Можно отправить и незаполненным — ИИ сам задаст вопросы. Подробное ТЗ — папка `TechnicalSpecification/` (Obsidian).

Ты — senior-разработчик на C# и .NET. Сделай настольную программу для Windows по этому ТЗ на стеке **.NET 10 · WPF · WPF-UI (Fluent) · CommunityToolkit.Mvvm · Microsoft.Extensions.Hosting · Serilog · EF Core (SQLite / PostgreSQL) · AngleSharp · ClosedXML · ScottPlot · xUnit v3 + Shouldly**.

- **Если у тебя есть доступ к файлам** (Claude Code, Cursor, Codex и т. п.): если проекта ещё нет, создай его:
  `dotnet new install NetAppStack` → `dotnet new netapp -n MyApp` (опции ниже) и работай в папке `MyApp`. В шаблоне уже есть фоновый сбор, таблица с фильтрами и статусами, логи, настройки, Excel, выпуск exe — замени демо на мою программу, оставив инфраструктуру. Первым прочитай `AGENTS.md`.
- **Если ты в обычном чате без доступа к файлам:** проект я создам сам этими командами. Давай мне команды по шагам и файлы целиком, с путями.
- **Незаполненные поля `«…»`:** спроси о них в первых вопросах или прими разумное решение и напиши, какое.
