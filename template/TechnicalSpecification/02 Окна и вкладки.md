# Окна и вкладки

> В шаблоне уже есть: главное окно с кнопкой «Обновить сейчас» / «Отмена», строкой состояния, меню «⋯» (Excel, CSV, папка данных, собрать заново); вкладки «Данные», «График», «Логи»; окна «Настройки» и «Справка».

- **вкладки** — список вкладок главного окна по порядку. Для каждой новой — заметка в папке `Вкладки` по шаблону [[Шаблон вкладки]].
- **окна** — отдельные окна (диалоги): карточка записи, мастер импорта и т. п.

## Главное окно

- Что видно сразу после запуска: «…»
- Горячие клавиши: F5 — обновить, Ctrl+E — Excel, F1 — справка; свои: «…»
