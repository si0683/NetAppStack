# Техническое задание: настольная программа для Windows

Сначала ТЗ — потом код. Эта папка — хранилище **Obsidian**: заполните заметки по порядку, и ИИ-ассистент сделает программу на стеке **.NET 10 · WPF · WPF-UI · CommunityToolkit.Mvvm · Microsoft.Extensions.Hosting · Serilog · EF Core (SQLite / PostgreSQL) · AngleSharp · ClosedXML · ScottPlot · xUnit** без лишних вопросов.

## Как заполнять

1. Установите [Obsidian](https://obsidian.md) (бесплатно) → «Открыть папку как хранилище» → выберите эту папку `TechnicalSpecification`.
2. Откройте [[00 Паспорт]] и идите сверху вниз: 01 → 10. Каждая заметка — один раздел ТЗ.
3. **Поля вверху заметки** (свойства) — короткие ответы: да/нет, интервал, база. Заполняйте их первыми.
4. **Текст ниже** — подробности: отмечайте `[x]` нужное, заменяйте `«…»` своим, лишнее удаляйте.
5. Повторяющиеся вещи — отдельные заметки в папках: **Источники** (откуда берём данные), **Вкладки** (экраны программы). Новая — скопируйте шаблон из `_Шаблоны` (или команда Obsidian «Шаблоны: вставить шаблон»).
6. **Карта ТЗ.canvas** — всё ТЗ на одном экране. Двойной щелчок по пустому месту — новая карточка, перетащите заметку из списка слева — карточка-ссылка.
7. Когда в [[10 Этапы и готовность]] отмечены все пункты «ТЗ готово» — отдавайте ИИ.

Не знаете, что выбрать — оставьте поле пустым: ИИ предложит вариант и запишет его в [[09 Решения и вопросы]].

## Как отдать ИИ

Положите папку в проект (или создайте проект — в нём она уже есть) и напишите ассистенту (Claude Code, Cursor, Codex…):

> Прочитай TechnicalSpecification/ (начни с README.md и 00 Паспорт.md, затем все заметки, папки и .canvas). Задай вопросы по пустым и противоречивым местам, покажи план этапов и после моего «ок» сделай программу.

## Для ИИ-ассистента: как читать это ТЗ

- Порядок: `00 Паспорт.md` → `01`…`10` → папки (`Источники`, `Вкладки`) → `.canvas` (JSON: `nodes` — карточки, у `type: "file"` поле `file` — путь к заметке; `edges` — стрелки).
- Свойства YAML вверху заметок — обязательные решения; текст ниже — уточнения. При противоречии спроси.
- Проект создаётся командой `dotnet new netapp -n <Имя>` с опциями из [[00 Паспорт]]: `--db sqlite|postgres`, `--charts`, `--tray`, `--updates`, `--repo`, `--company`. Если проект уже создан — работай в нём по правилам `AGENTS.md`.
- Каждый источник из папки `Источники` — отдельный `ICollector` с тестом разбора на сохранённой странице или ответе API.
- Пустое поле или `«…»` — прими разумное решение по стеку шаблона и запиши в `09 Решения и вопросы.md` (дата, решение, почему).
- Делай по этапам из `10 Этапы и готовность.md`; после каждого этапа отмечай сделанное.
- Изменилось решение по ходу работы — обнови ТЗ, чтобы оно оставалось правдой о программе.
