# Выпуск и обновления

- **как_раздаём** — `один exe в GitHub Releases` (шаблон) · `Setup.exe + автообновление` (опция `--updates`, Velopack) · `только у себя`.
- **подпись_exe** — подписать сертификатом, чтобы Windows SmartScreen не пугал «неизвестным издателем» (сертификат платный).

## Как выпускаем

`git tag v1.0.0` → `git push --tags` → GitHub Actions прогоняет тесты и выкладывает exe (`.github/workflows/release.yml`).

## Версии

- Номер версии: `v1.2.3` — «новое.функция.исправление».
- Что нового — в описании релиза (собирается из коммитов) и в `CHANGELOG.md`.
