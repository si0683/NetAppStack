NetAppStack
GitHub

Программа для Windows на C# одной командой

Фоновый сбор данных, таблица со статусами, логи, настройки, Excel и выпуск одним exe — уже внутри. Остаётся написать свои источники данных.

Как начать

  1. Установите шаблон
    dotnet new install NetAppStack
  2. Создайте проект
    dotnet new netapp -n MyApp
  3. Запустите
    dotnet run --project MyApp/src/MyApp
  4. Выпустите exegit tag v1.0.0 && git push --tags — тесты и exe в GitHub Releases.

Нужен .NET SDK 10. Опции: --db sqlite|postgres, --charts, --tray, --updates. ТЗ для нейросети — PROMT.md.
