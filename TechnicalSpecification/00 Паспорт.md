# Паспорт проекта

> Поля сверху (свойства Obsidian) — главные решения: их читает ИИ при создании проекта. Ниже — подробности словами. Пустое поле = «реши сам и запиши решение в [[09 Решения и вопросы]]».

## Поля

- **название** — как программа называется в заголовке окна и в Releases.
- **имя_проекта** — латиница без пробелов (`LeadCollector`): имя exe, папок и пространств имён. Потом не меняется.
- **тип** — одно из: сборщик данных / мониторинг · аналитика и отчёты · торговый / биржевой инструмент · справочник / база · утилита · другое.
- **статус** — `черновик` → `на проверке` → `готово` (можно отдавать ИИ) → `в разработке`.
- **база** — `sqlite` (файл рядом с программой, для себя) или `postgres` (общая база на сервере, несколько компьютеров).
- **график** — нужна вкладка с графиками (ScottPlot).
- **трей** — значок у часов, работа в фоне при закрытом окне, уведомления о новом.
- **автообновление** — установщик Setup.exe и обновление из GitHub Releases (Velopack). Без него — один exe, обновление вручную.
- **репозиторий** — `https://github.com/владелец/проект` (для ссылок и обновлений).

## Создание проекта

```
dotnet new netapp -n <имя_проекта> --db <база> --charts <график> --tray <трей> --updates <автообновление> --repo <репозиторий> --company "<автор>"
```

## Главное в одной фразе

«…» — например: «Каждый час собирает новые стройки по Самарской области с госзакупок и сайтов администраций и показывает списком для прозвона».
