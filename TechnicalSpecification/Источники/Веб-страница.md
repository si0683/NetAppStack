# Веб-страница (пример из шаблона)

Скачивает одну страницу и разбирает список по CSS-селекторам из «Настроек». Код — `WebListCollector` + `HtmlListParser`, тест — `ParsingAndExportTests` на `Fixtures/list-page.html`.

## Что берём

| Поле записи | Где на странице | Пример |
| --- | --- | --- |
| Номер (ExternalId) | адрес ссылки | `https://example.com/objects/101` |
| Название | текст ссылки | «Ремонт дороги по ул. Мира» |
| Дата | `time[datetime]` или текст | `2026-11-03T09:30:00Z`, `05.11.2026` |
| Категория | селектор категории | «Дороги» |

## Фильтр

Нет — берутся все элементы списка.
