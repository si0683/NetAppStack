# Этапы и готовность

## ТЗ готово, когда

- [ ] [[00 Паспорт]]: название, имя проекта, база, опции
- [ ] [[01 Идея и пользователи]]: главный сценарий по шагам
- [ ] [[03 Источники данных]]: у каждого источника есть заметка в папке `Источники`
- [ ] [[04 Данные и таблица]]: поля записи
- [ ] [[05 Функции]]: функции главного сценария
- [ ] Открытые вопросы в [[09 Решения и вопросы]] закрыты или помечены «решит ИИ»

Всё отмечено → `тз_готово: true` и статус `готово` в [[00 Паспорт]].

## Этапы разработки

Каждый этап заканчивается программой, которую можно запустить.

1. [ ] **Этап 1.** Проект из шаблона, свои поля записи и колонки, демо-данные — срок: «…»
2. [ ] **Этап 2.** Первый настоящий источник + тест разбора — срок: «…»
3. [ ] **Этап 3.** Остальные источники — срок: «…»
4. [ ] **Этап 4.** Функции, фильтры, отчёты — срок: «…»
5. [ ] **Этап 5.** Полировка, справка, выпуск v1.0.0 — срок: «…»

## Первая версия готова, когда

- [ ] Главный сценарий проходит от начала до конца
- [ ] `dotnet test` зелёный, в «Логах» нет ошибок при обычной работе
- [ ] Программа работает с exe из GitHub Releases на чистом компьютере
